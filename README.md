# Project1

## Описание
Проект Project1 - это проект по созданию новой фичи для личного кабинета клиента банка.
Он показывает несколько последних успешных банковский операций клиента.

## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/mihalevalubov326-Spec/Project1.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Использование:

1. Откройте приложение в вашем веб-браузере.
2. Создайте новый проект и начните добавлять задачи.
3. Назначайте сроки выполнения и приоритеты для задач, чтобы эффективно управлять проектами.
