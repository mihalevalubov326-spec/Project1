# Project1

## Описание
Проект Project1 - это проект по созданию новой фичи для личного кабинета клиента банка.
Он показывает несколько последних успешных банковский операций клиента.
В проекте реализованы функции маскировки номера банковской карты и банковского счёта, а также списки транзакций.
## Установка:
1. Клонируйте репозиторий:
```
git clone https://github.com/mihalevalubov326-Spec/Project1.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
3. Создайте базу данных и выполните миграции:
```
python manage.py migrate
```

4. Запустите локальный сервер:
```
python manage.py runserver
```
